# 🚗 Synthetic Vehicle Suspension & Telemetry Dataset (100Hz)

A high-frequency, physics-calculated synthetic dataset simulating 100Hz IMU telematics and dynamic ground clearance for automotive active chassis control, pothole detection, and predictive maintenance ML models.

---

## 📌 Dataset Overview

* *Sampling Frequency:* 100 Hz (10 ms time intervals)
* *Simulation Engine:* 2-DOF Quarter-Car Mass-Spring-Damper Physics Model (Euler-Cromer Numerical Integration)
* *Format:* CSV (synthetic_suspension_physics_scratch.csv)
* *Hazard Types Simulated:* POTHOLE, SPEED_BUMP, EVASIVE_SWERVE, ROUGH_ROAD, SMOOTH_HIGHWAY
* *Sensor Noise Profile:* Realistic MEMS accelerometer noise floor ($\sigma = 0.015\text{ g}$) and gyroscope angular rate jitter

| tire_normal_force_n | Float | N | Contact normal force between tire footprint and road surface |

## 🔬 Mathematical & Physical Foundation

The dataset is generated by integrating the coupled differential equations of motion for a standard mid-size passenger sedan:

### 1. Mass-Spring-Damper Equations
$$\ddot{z}_s = \frac{K_s (z_u - z_s) + C_s (\dot{z}_u - \dot{z}_s)}{M_s}$$

$$\ddot{z}_u = \frac{K_s (z_s - z_u) + C_s (\dot{z}_s - \dot{z}_u) + K_t (r(t) - z_u)}{M_u}$$

### 2. Dynamic Ground Clearance Physics
$$\text{Clearance}(t) = \text{Baseline Clearance} + z_s(t) - r(t)$$

### 3. Simulation Physical Parameters

| Parameter | Symbol | Value | Description |
| :--- | :--- | :--- | :--- |
| *Sprung Mass* | $M_s$ | $400.0\text{ kg}$ | $1/4$ chassis mass (~1,600 kg vehicle) |
| *Unsprung Mass* | $M_u$ | $45.0\text{ kg}$ | Wheel, tire, and hub assembly mass |
| *Suspension Stiffness* | $K_s$ | $28,000.0\text{ N/m}$ | Spring elasticity constant |
| *Damping Coefficient* | $C_s$ | $2,200.0\text{ N}\cdot\text{s/m}$ | Shock absorber resistance coefficient |
| *Tire Stiffness* | $K_t$ | $190,000.0\text{ N/m}$ | Radial tire elasticity |
| *Gravity* | $G$ | $9.81\text{ m/s}^2$ | Standard gravitational acceleration |
