# 🛣️ RoadSense AI

**DSP-Based Road Condition Monitoring and Pothole Detection Using FFT, FIR/IIR Filters, and Machine Learning**

A complete Digital Signal Processing mini-project for Third-Year Electronics and Telecommunication Engineering students.

> ⚠️ **Synthetic Data Disclosure:** This project uses a synthetic dataset generated by a 2-DOF quarter-car mass-spring-damper physics simulation (100 Hz, MEMS accelerometer noise). The data does **not** represent real-world vehicle sensor recordings.

---

## 📐 Pipeline

```
CSV Dataset → Data Inspection → Preprocessing → Sampling Analysis
→ FIR/IIR Filtering → FFT Analysis → Feature Extraction
→ ML Classification → Evaluation → Interactive Dashboard
```

## 📊 Dataset

- **Source:** Synthetic Vehicle Suspension & Telemetry Dataset (100 Hz)
- **Simulation Engine:** 2-DOF Quarter-Car Mass-Spring-Damper (Euler-Cromer)
- **Sampling Frequency:** 100 Hz (10 ms intervals)
- **Primary Signal:** `chassis_accel_z_g` — vertical chassis acceleration (g)
- **Hazard Classes in this sample:**
  - `POTHOLE`
  - `SPEED_BUMP`
  - `SMOOTH_HIGHWAY`
  - `EVASIVE_SWERVE`
- **Rows:** 1001 (4 simulation runs × ~300 samples each)

## 🚀 Quick Start (Windows PowerShell)

### 1. Open the project folder

```powershell
cd "C:\Users\VEDAN\DSP TY\roadsense-ai"
```

### 2. Create a virtual environment

```powershell
python -m venv .venv
```

### 3. Activate the virtual environment

```powershell
.venv\Scripts\Activate.ps1
```

> **If you get an execution-policy error**, run this once as Administrator:
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

### 4. Install dependencies

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 5. Run the tests

```powershell
python -m pytest tests/ -v
```

### 6. Launch the Cyber-Telemetry Cockpit

**Option A — Double-click launcher (Easiest):**
Double-click `run_app.bat` inside `roadsense-ai/`.

**Option B — PowerShell command:**
```powershell
python -m uvicorn server:app --port 8000
```

The application will open in your default browser at `http://localhost:8000`.

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| `python` not found | Install Python 3.9+ from [python.org](https://python.org) and add to PATH |
| `ModuleNotFoundError` | Ensure `.venv` is activated and run `pip install -r requirements.txt` |
| CSV not found error | Place the dataset CSV in the `data/` directory |
| Execution policy error | Run `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` in admin PowerShell |
| Server won't start | Ensure dependencies installed: `pip install -r requirements.txt` |
| Port 8000 in use | Run `python -m uvicorn server:app --port 8080` |

## 📝 Key DSP Concepts Demonstrated

1. **Sampling:** 100 Hz discrete-time sampling, Nyquist frequency (50 Hz), aliasing
2. **FIR Filters:** Window-method design (`scipy.signal.firwin`), configurable order/cutoff
3. **IIR Filters:** Butterworth design (second-order sections for stability)
4. **FFT:** Single-sided magnitude spectrum, window functions, spectral leakage
5. **Feature Extraction:** RMS, crest factor, spectral centroid, band energies
6. **ML Classification:** Random Forest, SVM with group-based train/test split
